Long-only pyramid trend bot trading cbBTC/USDC on 1-minute bars. One campaign per window: a half-size leg on a confirmed short uptrend, a second half when the 4-hour trend confirms, then hold with a hard reversal exit. Dev window: +$26.44 net PnL on 2 trades, 1.98% max drawdown.

## Run it

```sh
python3 -P -s main.py
```
